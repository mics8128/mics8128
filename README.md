## How I Think About Engineering

I care about systems that are useful, maintainable, and actually adopted by users.

My approach:

1. Understand the real workflow before writing code
2. Build the smallest useful version first
3. Connect systems instead of forcing people to copy-paste data
4. Use AI where it creates leverage, not just novelty
5. Keep humans in the loop when judgment matters
6. Automate repeated work, document the edge cases, and improve over time
